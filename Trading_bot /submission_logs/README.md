# Submission log samples

The assignment asks for **log files from at least one MARKET order and one LIMIT order** placed on testnet.

After you run the CLI successfully:

1. Use separate `--log-file` names (see main `README.md`) **or** copy `logs/trading_bot.log` after each run.
2. Place copies here as e.g. `market_order.log` and `limit_order.log` before zipping or linking your repo.

The files `sample_market_order.log`, `sample_limit_order.log`, and `sample_stop_order.log` (bonus stop-limit) illustrate **format and content** only (timestamps and IDs will differ on your machine). Replace them with **your real** testnet logs for submission.
